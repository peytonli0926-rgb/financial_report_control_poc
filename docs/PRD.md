# 财报智控平台 Local POC 产品需求文档

## 1. 产品概述

财报智控平台 Local POC 是一套面向银行财报数据处理和披露校验的本地化工具。第一版聚焦“重庆农商行 2025 年资产负债表校验”场景，通过本地页面完成基础文件上传、加工规则解析、资产负债表生成、PDF 年报披露金额提取与一致性校验。

本项目不依赖外网、不调用外部 API、不接入大语言模型，适合在内网、专机或审计现场等受控环境中运行。

## 2. 产品定位

本产品定位为财报生成与披露校验的本地智能控制工具，用于提升银行年报编制、复核和审计支持过程中的自动化程度。

核心价值：

- 本地离线：敏感财务数据不出本机。
- 流程闭环：从基础文件到报表生成，再到 PDF 披露校验。
- 可追溯：保留规则解析结果、PDF 原始文本和校验差异。
- 可落地：基于 Python、Streamlit、pandas、openpyxl、PyMuPDF 实现，不依赖云服务。

## 3. 目标用户

- 银行财务报表编制人员
- 财报复核人员
- 内控、合规和审计支持团队
- 数据治理和财务系统实施团队

## 4. 第一版范围

第一版 POC 仅支持：

- 重庆农商行 2025 年资产负债表场景
- 4 个基础 Excel 文件上传和完整性检查
- 1 个加工规则 Excel 文件解析
- 资产负债表生成版 Excel 输出
- 1 个年度报告 PDF 文件解析
- 资产负债表生成金额与 PDF 披露金额比对

第一版暂不支持：

- 从科目余额表重新计算全部指标
- 多银行、多年度、多报表模板自动切换
- OCR 图片型 PDF 识别
- 权限管理、用户管理、任务调度
- 外部系统接口集成

## 5. 业务流程

### 5.1 上传基础文件

系统支持上传并检查 4 个 `1-` 开头的基础文件：

- `1-1-20251231科目余额表.xlsx`
- `1-2-20251231审计调整_底稿_母行.xlsx`
- `1-3-20251231审计调整_底稿_子公司.xlsx`
- `1-4-20251231审计调整_合并抵消底稿.xlsx`

页面会自动检查 `data/upload/` 下是否已经存在对应文件。用户可以沿用默认文件，也可以重新上传。

### 5.2 上传并解析加工规则

系统支持上传 `2-1-报表指标-加工规则.xlsx`，自动识别其中与“合并及母公司资产负债表”相关的规则。

解析结果保存到：

```text
data/output/资产负债表规则解析结果.xlsx
```

### 5.3 生成资产负债表

用户点击“生成资产负债表”后，系统执行：

- 解析资产负债表规则
- 提取集团金额和本行金额
- 生成标准资产负债表结果表
- 检查集团和本行资产负债是否平衡
- 输出 Excel 报告

输出文件：

```text
data/output/资产负债表生成版.xlsx
data/output/资产负债表生成结果_中间表.xlsx
```

### 5.4 执行 PDF 校验

系统支持上传 `4-1-重庆农村商业银行股份有限公司2025年年度报告.pdf`，自动定位资产负债表相关页面，提取披露金额，并与生成结果进行比对。

输出文件：

```text
data/output/PDF披露金额解析结果.xlsx
data/output/PDF校验结果.xlsx
```

## 6. 关键功能

### 6.1 文件配置驱动

上传文件清单由 `config/file_templates.yaml` 管理，包含：

- `file_key`
- `display_name`
- `required`
- `prefix`
- `file_type`
- `description`

### 6.2 规则解析

系统自动扫描规则 Excel 的全部 sheet，不写死 sheet 名，查找包含“合并及母公司资产负债表”的规则行。

### 6.3 资产负债表生成

系统根据规则解析结果生成标准资产负债表，输出字段包括：

- 序号
- 报表名称
- 指标编码
- 指标名称
- 数据来源
- 指标类型
- 加工规则
- 生成金额-集团
- 生成金额-本行

### 6.4 平衡检查

系统检查：

```text
资产总计 = 负债和股东权益总计
```

分别输出集团和本行平衡状态。

### 6.5 PDF 披露金额提取

系统使用 PyMuPDF 读取 PDF 文本，定位资产负债表页面，并根据指标名称提取集团和本行披露金额。

支持：

- 千分位逗号金额
- 负数
- 括号负数
- PDF 表格中项目名和金额分行展示的情况
- 常见项目别名匹配，例如“资产总额”匹配“资产总计”

### 6.6 PDF 一致性校验

系统根据“指标名称”匹配生成结果和 PDF 披露结果。

判断规则：

- 差异绝对值小于等于 1 千元：一致
- PDF 金额为空：未提取到 PDF 披露值
- 其他情况：不一致

## 7. 页面统计指标

页面展示以下关键统计：

- 资产负债表规则数量
- 集团是否平衡
- 本行是否平衡
- PDF 提取成功项目数
- 一致项目数
- 不一致项目数
- 未提取项目数

## 8. 技术架构

### 8.1 前端页面

- Streamlit

### 8.2 数据处理

- pandas
- openpyxl
- PyMuPDF
- PyYAML

### 8.3 核心模块

```text
engine/file_manager.py      文件配置、上传和完整性检查
engine/rule_parser.py       加工规则解析
engine/balance_sheet.py     资产负债表生成和平衡检查
engine/pdf_extractor.py     PDF 文本和披露金额提取
engine/validator.py         生成金额与 PDF 披露金额校验
engine/report_writer.py     Excel 报告输出
```

## 9. 数据安全说明

本项目以本地离线方式运行：

- 不上传文件到外部服务器
- 不调用大语言模型
- 不调用云端 OCR
- 不调用外部 API
- 不需要互联网连接

所有输入、输出和中间结果均保存在本地目录。

## 10. 对外宣传口径

财报智控平台 Local POC 通过本地化、规则化、可追溯的方式，将财报生成与 PDF 披露校验流程串联起来。系统能够在不依赖外网和外部模型的前提下，完成银行资产负债表生成、平衡检查、年报披露金额提取和差异清单输出，为财报编制、复核和审计支持提供轻量级自动化工具。
