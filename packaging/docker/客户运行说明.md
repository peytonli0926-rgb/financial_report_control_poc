# IFRS 18 Docker 运行说明

## 前置条件

- Windows 10/11 或服务器环境已安装 Docker Desktop / Docker Engine。
- Docker 服务已启动。

## 启动

解压交付包后，双击：

```text
启动_IFRS18_Docker.bat
```

或在 PowerShell 中执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_loaded_image.ps1
```

启动后访问：

```text
http://127.0.0.1:8502
```

## 停止

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\stop_container.ps1
```

## 数据持久化

容器将 `data/output` 挂载到 Docker volume：

```text
ifrs18-report-platform-output
```

因此容器重启后输出结果仍会保留。

## 注意事项

- 该 Docker 包内置 IFRS 18 程序、配置文件和演示数据，不依赖客户本机 Python 环境。
- 容器内不能直接调用客户 Windows 桌面的 Excel 程序；点击追溯文件链接时，页面会提供文件下载。
